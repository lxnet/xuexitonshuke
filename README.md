一款面向高校在线课程的浏览器学习助手，由 leo 开发维护。自动完成超星学习通与智慧树平台的视频与图文文档学习任务点，跳过已完成内容与章节测验，自动强穿各类拦截弹窗并进入下一节。

> ⚠️
> **本扩展仅供技术学习与交流使用，严禁用于违反学校规定的行为。**



***

## ✨ 功能特性

### 📺 智能排队刷课



* 穿透旧版（顶层 `.ans-cc`）与新版（卡片 iframe）两代页面结构，直接解析 `mArg` 底层数据，精准锁定未完成任务。

* 视频与图文 PPT 智能排队，完成一个自动接管下一个。

* 视频静音原速播放（不修改倍速，规避服务端风控），自带防暂停机制，播放到设定百分比即完成任务。

### ⏭️ 无感跳过与弹窗强穿



* 通过 `mArg type=workid` 识别章节测验任务点，自动跳过不卡队列。

* 运行期间持续巡检拦截弹窗（任务未完成确认 / 笔记未保存 / 每日上限），自动点击放行。

* 任务完成后自动点击 "下一节"，多卡片、跨章节连续推进。

### 📝 AI 自动答题（可选）



* 在测验页一键提取题干、选项与题型，本地保存。

* 支持配置任意 **OpenAI 兼容接口**（如小米 MiMo、DeepSeek），自动作答→点选→提交，支持视频内弹题连答。

* 本地解析超星 `font-cxsecret` 加密字体，用字形模板匹配还原题干后再发送模型（完全离线）。

* 未启用 AI 时保持原逻辑：直接跳过测验。

### 🌲 双平台支持



* **学习通**（超星 / 尔雅 /erya100）：完整刷课 + AI 答题链路。

* **智慧树**：视频自动续播、PDF 文档自动跳转下一未完成知识点。

## 📥 安装方式

微软商店审核通过，可使用商店安装，推荐使用**开发者模式手动加载**：
## 安装
### 方式1：Edge扩展商店（推荐）
👉 [前往 Edge 扩展商店 - Leo帮你学](https://microsoftedge.microsoft.com/addons/detail/leo%E5%B8%AE%E4%BD%A0%E5%AD%A6/ghebfknknjpinckeddpibelpmenncbep)
1. 打开链接，点击**添加到 Microsoft Edge**
2. 在弹窗确认添加，完成安装

### 方式2：本地加载开发版
1. 下载源码并解压到本地文件夹
2. Edge地址栏输入 `edge://extensions/` 回车
3. 开启**开发者模式**
4. 点击「加载已解压的扩展」，选中解压目录

> ⚠️ 离线安装后不要移动文件夹，否则扩展会失效。
### Chrome / Edge（开发者模式）



1. 从 GitHub 仓库下载本项目源码（ZIP 解压或 `git clone`）。

2. 浏览器地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。

3. 右上角打开 **开发者模式**。

4. 点击 **加载已解压的扩展程序**，选择项目根目录（包含 `manifest.json` 的文件夹）。

5. 打开学习通或智慧树课程页，右上角出现控制面板即安装成功。

## 🚀 使用指南



1. 进入带有视频或文档的章节页面，打开扩展面板，点击 **开始刷课**。

2. 扩展自动排队完成任务点、强穿弹窗并进入下一节。

3. **AI 答题**：展开面板中 "AI 答题设置"，填写 Base URL / API Key / 模型名并保存，勾选 "启用"。

* 配置教程见：


  * [小米 MiMo 配置教程](https://my.feishu.cn/wiki/YiCWwggBNiBBGgkOWHZc05Jk6Qh)

  * [DeepSeek 配置教程](https://my.feishu.cn/wiki/Cwj8wrJI8iPx7JkVFiqcQiRc6xb)

1. 未启用 AI 时，扩展会自动跳过章节测验。

### AI 答题常见问题



* **HTTP 401**：API Key 与 Base URL 不属于同一服务（如把中转站 Key 发到了官方地址），请核对三项配置一致。

* **HTTP 404**：Base URL 路径不完整，通常需以 `/v1` 结尾。

* **配置不跨安装共享**：换电脑或重装扩展后需重新填写三项配置。

* **Key 格式**：只填密钥本身（如 `sk-xxx`），扩展会自动处理 `Bearer` 前缀。

## 🔧 项目结构



```
leo-helpyou-addon/
├── manifest.json      # MV3 清单
├── utils.js           # 平台检测 / 存储封装 / 工具函数
├── ui.js              # 控制面板 UI
├── video.js           # 视频任务模块（原速静音 + 防风控）
├── doc.js             # 文档/PPT 翻页模块
├── quiz.js            # 测验识别与题目提取
├── decipher.js        # 超星加密字体离线解密
├── ai.js              # AI 自动答题（OpenAI 兼容接口）
├── zhs.js             # 智慧树平台适配器
├── main.js            # 核心调度器 / 弹窗巡检 / 消息路由
├── candidates.js       # GB2312 候选汉字集（字体解密用）
├── icons/             # 扩展图标
└── _locales/zh_CN/    # 简体中文语言包
```
